asm

The universal skill manager for AI coding agents.
https://github.com/luongnv89/asm
agent-skill-manager is a scriptable CLI for installing, searching, and auditing AI agent skills across 21 supported providers. It provides machine-readable JSON output and non-interactive flags to enable seamless integration with automation workflows. The tool includes features for security scanning, residency cost analysis, and a local TUI for browsing the skill catalog.

open-intelligent-ui

An open-source take on ChatGPT's Intelligent UI: answers stream as interactive UI (maps, photos, charts, drawings and working tools). Built with OpenUI.
https://github.com/thesysdev/open-intelligent-ui
Open Intelligent UI is an open-source implementation of ChatGPT's interactive interface built on OpenUI Lang 1.0 to render dynamic, state-driven components like maps and charts. The project provides a comprehensive library of layout, text, input, media, and function primitives that models arrange programmatically without fixed layouts. It supports deployment via OpenUI Cloud Gateway, any OpenAI-compatible API, or local Ollama models, featuring dedicated demos for Clash Royale and Chess coaching.

Legends-Of-Heroes

A battle of balls game, lol style, AI Agents base, support agent skills & unityMCP. 基于ET 10的双端C#游戏框架(.net10 + Unity2022.3.62, EUI+Luban+YooAsset)，包含战斗系统（技能/buff/行为树），内置LOL风格球球大战demo
https://github.com/FlameskyDexive/Legends-Of-Heroes
Legends-Of-Heroes is a production-ready open-source multiplayer game framework built with ET 8.x, Unity 2022.3, and .NET 10 using state synchronization for server-authoritative gameplay logic. It features an ECS-based skill and Buff system, HybridCLR hot-update pipeline, YooAsset management, and pluggable AI agents integrated via AIBridge CLI and UnityMCP. The project provides a complete architecture diagram, networking capabilities with TCP/KCP/WebSocket support, and requires Visual Studio 2022 or Rider with .NET SDK 10.0 to run.
