Hexabot

Hexabot v3 is an AI workflow automation platform, combining workflows, actions, agents, and conversational channels in one runtime.
https://github.com/hexabot-ai/Hexabot
Hexabot v3 is an automation platform that combines agentic workflows, actions, and conversational channels in one runtime with first-class AI capabilities. It enables building workflows across channels using YAML, tools, MCP, memory, and RAG, supported by a schema-first architecture and TypeORM data layer. Users can quickly start by installing the CLI to create and run projects locally or via Docker, with contributions guided by specific monorepo instructions.

Mysti

AI coding dream team of agents for VS Code. Claude Code + openai Codex collaborate in brainstorm mode, debate solutions, and synthesize the best approach for your code.
https://github.com/DeepMyst/Mysti
Mysti is a VS Code extension that unifies multiple coding agents like Claude Code and Codex into a single shared workflow for collaborative development. It enables users to compare independent agent responses, manage explicit handoffs between tasks, and utilize features like Canvas and Brainstorm for decision-making. The project is currently in Beta 2 status, supporting 16 provider adapters and requiring VS Code 1.86 or newer for installation and operation.

binance-skills-hub

Binance Skills Hub is an open skills marketplace that gives AI agents native access to crypto
https://github.com/binance/binance-skills-hub
Binance Skills Hub is an open marketplace enabling AI agents to interact with the crypto ecosystem via natural language commands. It supports various frameworks like LangChain and CrewAI, requiring Node.js 22+ for installation through a single command. Contributors can add new skills by following specific formatting guidelines, while users must adhere to strict security and risk disclaimers.
