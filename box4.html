LuaN1aoAgent

LuaN1aoAgent is a fully autonomous AI-driven penetration testing agent powered by graph-based cognitive reasoning.
https://github.com/SanMuzZzZz/LuaN1aoAgent
LuaN1aoAgent v2 is a cognitive-driven autonomous security agent built on TypeScript and the Pi SDK for authorized pentesting. It utilizes a Planner-Executor-Observer architecture with causal graph reasoning to maintain traceable evidence and dynamic task planning. The system features sandbox isolation, durable runtime state, and interactive workbenches for observing and controlling security research sessions.

chidori

The agent framework where every run is durable, replayable, and resumable by default.
https://github.com/ThousandBirdsInc/chidori
Chidori is a durable TypeScript agent framework built on a Rust core that records every side effect as a host call for default checkpointing and replay. It enables byte-identical, zero-cost debugging and crash recovery by allowing runs to be paused, resumed, or re-executed from disk without re-calling LLMs. The system operates via a single self-contained binary with an embedded JavaScript engine, requiring no Node.js, native bindings, or external runtime dependencies.

tools

A set of tools that gives agents powerful capabilities.
https://github.com/strands-agents/tools
Strands Agents Tools is a community-driven Python library providing a comprehensive suite of tools to enable AI agents to perform file operations, shell commands, web searches, and AWS interactions. The repository includes extensive documentation on installation, usage examples for various integrations like Tavily and Exa, and detailed configuration via environment variables. Many existing tools are deprecated in favor of native SDK capabilities or official MCP servers, with a migration guide provided to help users transition before version 0.9.0.
