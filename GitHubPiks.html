Today picks

  • t3code

    The best way to control Claude Code, Codex and more from any computer or phone
    T3 Code is an open-source control plane that runs coding agents on your machine and provides a unified interface for desktop, web, and mobile clients. It supports various agents like Claude Code and Codex, allowing users to manage subscriptions, switch models, and handle Git operations seamlessly across devices. Licensed under MIT, the project emphasizes performance, remote accessibility, and openness, inviting contributions through focused fixes and approved feature discussions. (t3code)

  • ui

    A library of behaviors for agents to build the next generation of user interfaces.
    UI SDK provides a library of behaviors for agents to build next-generation user interfaces with support for React, Vue, Svelte, Solid, and Web Components. It offers core functionality like keyboard navigation and focus management, allowing developers to define primitives and render them across different frameworks using `createParts`. The project is currently in beta, welcoming contributions via issues and pull requests while directing security reports to Vercel's responsible disclosure channel. (ui)

  • jupyter-ai

    An open source extension that connects AI agents to computational notebooks in JupyterLab.
    Jupyter AI is an open source extension that connects AI agents to computational notebooks in JupyterLab via a native chat UI. It supports multiple frontier agents through the Agent Client Protocol and allows file reading, terminal commands, and real-time collaboration with permission controls. The project consists of two packages, jupyter-ai and jupyter-ai-core, and is currently under incubation within the JupyterLab organization. (jupyter-ai)
